HARNaz Studio — وێبسایت + بەشی بەڕێوەبردنی تایبەت
====================================================

ئەم وەشانە چی تێدایە؟
- admin.html: پەڕەی چوونەژوورەوەی بەڕێوەبەر.
- admin.js / admin.css: چوونەژوورەوە، زیادکردن و سڕینەوەی وێنە.
- portfolio.js: دەرخستنی وێنە زیادکراوەکان لە پۆرتفۆلیۆی سایت.
- supabase-config.js: شوێنی دانانی لینکی پڕۆژە و کلیلی گشتی Supabase.
- supabase_setup.sql: کۆدی داتابەیس و پاراستنی دەسەڵاتەکان.

تێبینی گرنگ
بەشی Admin ئامادەیە، بەڵام تا پەیوەندی بە Supabase نەکرێت کار ناکات. ئەمە دەبێت تەنها جارێک ڕێکبخرێت.
هەرگیز service_role key یان secret key لە فایلەکانی وێبسایت مەنووسە. تەنها Project URL و publishable/anon key بەکاربهێنە.

هەنگاوەکانی ڕێکخستن
1. بچۆ بۆ https://supabase.com/dashboard و پڕۆژەیەکی نوێ بە ناوی HARNaz Studio Website دروست بکە. باشترە داتابەیسی وێبسایت لە داتابەیسی سیستەمی کارگە جیا بێت.
2. لە Authentication > Users هەژماری خۆت دروست بکە: ئیمەیڵ و وشەی نهێنییەکی بەهێز.
3. لە Authentication > Settings، هەڵبژاردەی Allow new users to sign up داخە. ئەمە ڕێگری دەکات لەوەی کەسانی تر خۆیان هەژمار دروست بکەن.
4. لە Storage، New bucket هەڵبژێرە. ناوی bucket بنووسە: portfolio و Public بکە. سنووری قەبارە 10MB و جۆری فایلەکان image/jpeg, image/png, image/webp, image/avif دابنێ.
5. لە Authentication > Users، UUID ـی هەژماری خۆت کۆپی بکە.
6. لە SQL Editor، فایلەکەی supabase_setup.sql بکەرەوە و هەموو کۆدەکەی تێدا دابنێ. لە کۆتایی فایلەکەدا ADMIN_USER_UUID بگۆڕە بە UUID ـی خۆت و دێڕی INSERT لە کۆتایی فایلەکە لە دۆخی comment دەربهێنە (دوو -- ـی سەرەتای دێڕەکە بسڕەوە)، پاشان Run بکە. ئەمە تەنها هەژماری خۆت وەک بەڕێوەبەر تۆمار دەکات.
7. لە Project Settings > API، Project URL و publishable key (یان anon key) کۆپی بکە. service_role/secret key مەکۆپی بکە.
8. فایلەی supabase-config.js بکەرەوە و دوو شوێنی PASTE... بە Project URL و publishable/anon key بگۆڕە.
9. تەواوی فایل و فۆڵدەرەکانی وێبسایت، لەگەڵ assets، بە GitHub Pages بڵاو بکەرەوە. فایلەکانی admin.html و admin.js و admin.css و portfolio.js و supabase-config.js و supabase_setup.sql لەگەڵیان بن.
10. لەسەر سایتەکەت بچۆ بۆ /admin.html و بە ئیمەیڵ و وشەی نهێنیی خۆت بچۆ ژوورەوە.

چۆن وێنە زیاد بکەیت؟
- ناوی پڕۆژە بنووسە.
- جۆری پڕۆژە هەڵبژێرە.
- وێنەکە هەڵبژێرە و دوگمەی بارکردن دابگرە.
- وێنەکە خۆکارانە لە Portfolio ـی سایتەکەدا دەردەکەوێت.
- لە داشبۆردەکە دەتوانیت وێنەی زیادکراو بسڕیتەوە.

وێنە سەرەتاییەکانی پۆرتفۆلیۆ هەر وەک خۆیان دەمێننەوە؛ بەشی بەڕێوەبردن وێنە نوێیەکانی تۆ زیاد دەکات و بەڕێوەیان دەبات.

پاراستن
- وشەی نهێنیت لەگەڵ کەس مەبەشە.
- service_role key لە هیچ فایلێکی وێبسایتدا دانەمەزرێنە.
- بەشی بەڕێوەبردن لە هەر کەسێک دەکرێت بکرێتەوە، بەڵام تەنها هەژماری تۆ دەسەڵاتی زیادکردن و سڕینەوەی وێنەی هەیە.
- Bucket ـەکە Public ـە بۆ ئەوەی سەردانکەرانی سایت بتوانن وێنەکان ببینن؛ بەڵام upload و delete تەنها بۆ بەڕێوەبەری تۆمارکراو ڕێگەپێدراوە.
